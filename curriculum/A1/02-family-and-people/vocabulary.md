# 📚 Vocabulary

## 👨‍👩‍👧‍👦 Family and People

| English | Azərbaycan dilində | Example                  |
| ------- | ------------------ | ------------------------ |
| mother  | ana                | My mother is a teacher.  |
| father  | ata                | My father is a driver.   |
| brother | qardaş             | My brother is a student. |
| sister  | bacı               | My sister is young.      |
| friend  | dost               | My friend is Ali.        |
| family  | ailə               | My family is small.      |
| name    | ad                 | My name is Anna.         |
| phone   | telefon            | My phone is here.        |
| book    | kitab              | This is my book.         |
| house   | ev                 | Our house is small.      |

## 🧠 Sözləri cümlə ilə öyrən

Sadəcə:

**mother = ana**

kimi əzbərləmə.

Bunun əvəzinə:

**My mother = mənim anam**

**My father = mənim atam**

**My friend = mənim dostum**

**My phone = mənim telefonum**

**My book = mənim kitabım**

**Our house = bizim evimiz**

kimi öyrən.
