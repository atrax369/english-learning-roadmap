# ✏️ Practice: A / An / The

## 1. Boşluğu doldur

Boşluğa **a, an** və ya **the** yaz.

1. This is ___ book.
2. This is ___ apple.
3. I have ___ phone.
4. She has ___ bag.
5. I see ___ dog.
6. ___ dog is black.
7. This is ___ computer.
8. I have ___ umbrella.

### Cavablar

1. a
2. an
3. a
4. a
5. a
6. the
7. a
8. an

---

## 2. Düzgün variantı seç

1. This is **a / an** pen.
2. I have **a / an** orange.
3. She has **a / an** computer.
4. This is **a / an** egg.
5. I see **a / the** dog. The dog is small.
6. He has **a / an** bag.

### Cavablar

1. a
2. an
3. a
4. an
5. a
6. a

---

## 3. Səhvləri düzəlt

Cümlələrdəki səhvi tap və düzəlt.

1. This is an book.
2. I have a apple.
3. She has an computer.
4. I see a dog. A dog is black.
5. This is an phone.

### Cavablar

1. This is **a book**.
2. I have **an apple**.
3. She has **a computer**.
4. I see a dog. **The dog** is black.
5. This is **a phone**.

## 5. Cümlə qur

Verilən sözlərdən düzgün cümlə qur.

1. is / This / a / book
2. an / This / apple / is
3. have / I / a / phone
4. is / The / blue / book
5. table / The / on / is / book / the

### Cavablar

1. This is a book.
2. This is an apple.
3. I have a phone.
4. The book is blue.
5. The book is on the table.

---

## 6. Öz cümlələrini yaz

Aşağıdakı sözlərlə öz cümləni qur:

## 7. Mini Speaking Practice

Otağındakı əşyalara bax və ingiliscə de:

> This is a table.

> This is a chair.

> This is a book.

> The book is on the table.

> This is my phone.

> This is a computer.

> The computer is near the window.

Sonra kitaba baxmadan otağındakı əşyalar haqqında **5–8 cümlə** danış.

## 🎯 Bugünkü məqsəd

Bu məşqlərdən sonra bacarmalısan:

* **a** və **an** seçmək
* **the** nə vaxt işlənir başa düşmək
* Əşyaları ingiliscə adlandırmaq
* Sadə cümlələr qurmaq
* Otağındakı əşyalar haqqında danışmaq
