# 🇬🇧 Lesson 03: A / An / The + Objects and Rooms

**Səviyyə:** A1
**Mövzu:** A / An / The + Əşyalar və otaq
**Müddət:** 60–70 dəqiqə

## 🎯 Dərsin məqsədi

Bu dərsin sonunda:

* `a` və `an` fərqini başa düşmək;
* `the` artiklindən istifadə etmək;
* əşyaları ingilis dilində adlandırmaq;
* otağı sadə cümlələrlə təsvir etmək;
* qısa mətn oxumaq və suallara cavab vermək;
* ən azı 1 dəqiqə otaq haqqında danışmaq

bacarılmalıdır.

## 🔥 Bugünkü əsas qayda

**a book** → bir kitab

**an apple** → bir alma

**the book** → həmin / məlum kitab

Əvvəlki dərsdən:

**my book** → mənim kitabım

**your book** → sənin kitabın

**his book** → onun kitabı, kişi

**her book** → onun kitabı, qadın

### Nümunə

> I have a book.
> My book is blue.
> The book is on the table.

Bu üç cümlə bugünkü dərsin əsas məntiqini göstərir.
